# ANPA_Simulation: Алгоритм локальной навигации с событийно‑временной логикой для обхода препятствий АНПА

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Python](https://img.shields.io/badge/python-3.8%2B-blue)](https://www.python.org/)

## 📌 О проекте

Данный репозиторий содержит программную реализацию алгоритма локальной навигации для автономного необитаемого подводного аппарата (АНПА).

Разработанный алгоритм обеспечивает:
- безопасное движение по траектории типа «меандр»;
- обнаружение и классификацию статических и динамических препятствий;
- событийно-временную логику переключения режимов (NORMAL, ATTENTION, AVOID, RETURN);
- автоматический возврат на исходный маршрут после обхода препятствия.

Программный модуль является частью выпускной квалификационной работы студента группы КТбо4-14 **А. С. Игнатенко** (Южный федеральный университет, Институт компьютерных технологий и информационной безопасности, кафедра синергетики и процессов управления).

## 🚀 Основные возможности

- Симуляция движения АНПА в 2D-пространстве
- Генерация маршрута «меандр» для зоны обследования
- Моделирование гидролокатора переднего обзора (сектор 60°, дальность 100 м)
- Реализация конечного автомата режимов обхода препятствий
- Визуализация траектории, зон безопасности и телеметрии в реальном времени
- Сохранение и загрузка результатов миссии в формате JSON
- Режим воспроизведения сохранённой миссии с анализом графиков

## 🛠 Технологии

- **Python 3.8+**
- **Pygame** — визуализация и пользовательский интерфейс
- **NumPy** — векторные и матричные вычисления
- **JSON** — логирование и хранение данных


## 🕹 Управление в программе

| Клавиша          | Действие                                      |
|------------------|-----------------------------------------------|
| `M`              | Переход в режим выбора зоны обследования      |
| `Space`          | Пауза / продолжение симуляции                 |
| `Ctrl + S`       | Сохранение текущей миссии в JSON              |
| `J`              | Загрузка сохранённой миссии                   |
| `G` (в реплее)   | Отображение графиков телеметрии               |
| `R`              | Сброс текущей миссии                          |
| `ESC`            | Выход из программы                            |
